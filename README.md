# plottoken

Plot filesystem token paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/plottoken/

## Install / run

```bash
git clone https://github.com/theworker02/plottoken.git
cd plottoken
node src/cli.js
node --test
```
